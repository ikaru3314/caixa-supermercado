# Caixa de Supermercado com IA — interface FreshCart

Projeto JavaFX de caixa de autoatendimento, com banco de dados e assistente de ajuda.

## Atualização visual

A identidade visual foi revisada com base na referência enviada:
- fundo azul-claro e superfícies brancas;
- cartões com cantos arredondados, bordas discretas e sombras suaves;
- azul para navegação e ações secundárias;
- verde para ações positivas e destaque de compra;
- tabela de produtos com cabeçalho claro e linhas alternadas;
- tela inicial com cartão de boas-vindas e chamada principal;
- painel de produtos com cartões de resumo, pesquisa e tabela.

As alterações de layout foram concentradas nas telas e no CSS. A lógica de navegação, cadastro/edição/exclusão de produtos e fluxo de compra foi mantida.

## Como executar

1. Abra a pasta no IntelliJ IDEA como projeto Maven.
2. Aguarde o carregamento das dependências.
3. Configure o banco conforme as instruções e o arquivo `banco/supermercado_mysql.sql`.
4. Execute `br.com.caixa.Launcher`.

O ambiente em que esta versão foi preparada não possui Maven instalado; portanto, a compilação e execução precisam ser conferidas no IntelliJ.
