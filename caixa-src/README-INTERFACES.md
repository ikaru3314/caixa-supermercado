# Atualização visual FreshCart

Este pacote aplica uma identidade visual consistente inspirada na referência FreshCart enviada pelo usuário.

## O que foi atualizado
- Paleta azul-claro, azul-marinho, branco e verde para ações positivas.
- Barra de etapas, cabeçalhos e botões com tamanhos e contrastes consistentes.
- Cartões brancos para CPF, escolha de pagamento, pagamento e finalização.
- Tela inicial com cartão de boas-vindas e botão principal verde.
- Painel de produtos com cartões de métricas, tabela e campo de pesquisa refinados.
- Tela de venda com painéis e indicadores na mesma identidade visual.
- Estilos de campos, tabelas, mensagens, cupom e diálogos.

## Abrir
Abra a pasta `caixa-src` no IntelliJ IDEA como projeto Maven e execute `br.com.caixa.Launcher`.

As funcionalidades de negócio foram preservadas; as alterações de layout concentram-se nas classes de interface e no CSS compartilhado. A compilação precisa ser validada no ambiente local, pois o Maven não está disponível neste ambiente de preparação.
